## Implementation
- `OpenVinoChatSession.GenerateWithStats` reads `NumGenerationTokens` and `Throughput.Mean` from native OpenVINO performance metrics.
- `DataService` persists those values on OpenVINO assistant messages.
- Existing `Chats.razor` rendering displays the values when present.
