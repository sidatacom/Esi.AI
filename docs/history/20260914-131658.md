# Sitzungsprotokoll

## Benutzeranfrage
Warum wird auf `/backends` weiterhin `NVIDIA GeForce RTX 4070` angezeigt, obwohl die Karte ausgebaut und nicht mehr vorhanden ist?

## Aktionsplan
- [x] Anzeigequelle in der Backend-Komponente identifizieren.
- [x] Prüfen, ob die GPU-Liste dynamisch erkannt oder statisch definiert wird.
- [x] Prüfen, ob gespeicherte Python-Backend-Einstellungen die Route zusätzlich festhalten.
- [x] Ergebnis zusammenfassen und mögliche Korrektur benennen.

## Ergebnis
Die Anzeige stammt aus einer statischen Route in `src/Esi.AI/Esi.AI.Studio.Client/Pages/Backends.razor`: `cuda:0` ist fest mit `NVIDIA GeForce RTX 4070` beschriftet. Der Zähler zählt diese Route als verfügbar, ohne die tatsächlich vorhandene Hardware zu enumerieren. Zusätzlich wird `cuda:0` als Standardroute verwendet, wenn keine Auswahl vorhanden ist.
