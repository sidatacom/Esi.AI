# Session request

User requested that clicking `Load model` publish a loaded-model collection event after loading starts, add the pending model to the client collection, and publish the final update after successful or unsuccessful loading.

- [complete] Record the final validation result.

## Implementation

- `ModelRuntime.TrackPendingModelAsync` already publishes `LoadedModel_Create` after registering the pending model.
- Changed the final lifecycle so `LoadedModel_Update` is published for both successful and unsuccessful loads.
- Failed loads still publish `LoadedModel_Delete` afterward, preserving collection CRUD semantics and removing the failed pending item.
- Added `LoadAsync_WhenOpenVinoModelPathIsMissing_PublishesCreateUpdateAndDelete` to verify `Create -> Update -> Delete` and the pending model snapshot.
