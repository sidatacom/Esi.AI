# Zusammenfassung
Ubuntu GNOME Remote Login fordert laut lokaler GNOME-Dokumentation systemweite RDP-Anmeldedaten und danach den GDM-Benutzer-Login. Der installierte Headless-Single-User-Modus wurde ohne Paketinstallation eingerichtet: TLS-Zertifikat und Schlüssel liegen in ~/.local/share/gnome-remote-desktop/, der Benutzerzugang ist konfiguriert, Port 3390 lauscht und der User-Dienst ist aktiviert. Der bisherige Systemdienst auf Port 3389 blieb als Rückweg aktiv. Dienstmeldungen bestätigen "RDP server started"; ein Client-Verbindungstest steht noch aus.
