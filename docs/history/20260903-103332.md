# Sitzungsprotokoll

## Anfrage
Prüfen, warum bei ausgewähltem Hugging-Face-Filter `SGLang` Modelle angezeigt werden, deren Tags nicht `sglang` enthalten.

## Arbeitsplan
- [ ] Filterauswahl, Request-Aufbau und Hugging-Face-Query lokal verfolgen.
- [ ] Prüfen, ob die Treffer durch die API-Filtersemantik oder durch fehlende lokale Nachfilterung entstehen.
- [ ] Ursache beheben oder, falls nur eine Erklärung erforderlich ist, die konkrete Ursache mit Codebeleg dokumentieren.
- [ ] Fokussierte Validierung ausführen.
- [ ] Abschlusszusammenfassung ergänzen.
