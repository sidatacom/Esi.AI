## Implementation Notes

## Registration Error Fix
- The Provider view previously called `Configuration.update()` unconditionally. On the affected active Extension Host, VS Code reported `esiAiStudio.loggingEnabled` as unregistered even though the installed manifest contained it.
- Version `0.1.15` now checks registration with `inspect()`, uses VS Code User Settings when available, and persists through extension `globalState` when the host registry is stale or missing. The provider reads the same fallback state, so the UI toggle remains functional without the error.
