# Session Log

## User Request
Thinking output from the Qwen model is displayed as normal chat text in VS Code.

## Initial Hypothesis
The provider forwards every OpenAI `delta.content` directly as a visible `LanguageModelTextPart`. Qwen emits internal reasoning inside `<think>...</think>`, and the installed VS Code API has no native thinking response part. A streaming-safe provider filter must therefore suppress those blocks before reporting visible text.

## Action Plan
- [ ] Add a streaming-safe filter for `<think>...</think>` blocks.
- [ ] Apply the filter to streaming and non-streaming provider responses.
- [ ] Increment, build, package, and install the provider version.
- [ ] Validate the provider build and filter behavior.

Investigation started.
