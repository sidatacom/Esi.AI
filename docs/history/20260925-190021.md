# Architecture And Limitations
- `FlowDefinition` remains the persisted workflow configuration; `ModelConfiguration` remains the backend allowlist. `DataService` orchestrates both ingress paths; the OpenAI controller remains the only API controller and retains its contract.
- The browser does not call the Optimajet Designer HTTP API. The Flow page stores the existing route JSON through SignalR, and the server translates its backend node into an Optimajet XML process.
- The Optimajet repository's EULA is not an OSI open-source license. Review licensing and redistribution rights before release. The upstream checkout remains a submodule; no Designer assets or copied upstream source were added to Esi.AI.
