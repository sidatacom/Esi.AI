## Findings from continuation

- A clean pipeline completed with `create_directory` alone and returned `[DONE]`.
- On a clean pipeline, `create_file` alone emitted only the initial SSE role chunk and then remained active until curl timed out; it did not reach `[DONE]`.
- The earlier `create_file` schema hypothesis is disproven. The subset tests performed after the first native failure were invalid because the OpenVINO runtime was already poisoned; no tool-count, description, or schema workaround was added.
- Removing tool descriptions while preserving the 91 parameter schemas still hung, so description size is not the root cause.
- After native failure, the Studio process can remain alive while the debug session disappears and `/v1/models` can still report the model as loaded. The confirmed lifecycle requirement is therefore to unload every backend immediately after an inference error and terminate the Studio process.
