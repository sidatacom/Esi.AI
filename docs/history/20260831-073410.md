## Architecture
No domain aggregate changes or domain events are required. The single existing OpenAI-compatible controller remains the application boundary and delegates inference to ModelRuntime.

## Changes
- OpenAI request, response, chunk, model-list, and error DTOs now live in `Esi.AI.Models`.
- `/v1/models` and `/v1/chat/completions` remain the only API routes.
- Non-streaming generation supports LLama, OpenVINO, vLLM, SGLang, and dotLLM.
- Streaming generation emits an initial assistant role chunk, content chunks, a stop chunk, and `data: [DONE]` for all supported backends.
- SSE JSON uses the same web naming policy as normal API responses.
- OpenVINO requests with multiple messages use the supplied history in the generated prompt.
- Invalid requests return `400`; no loaded model returns `503`; unsupported backends are rejected.
- API access remains intentionally local and unauthenticated for the current VS Code localhost workflow.
