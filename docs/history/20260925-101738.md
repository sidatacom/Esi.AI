# User Request
Migrate all Esi.AI inference backends consistently to the new separately packaged backend module architecture and shared `IBackendRuntime` contract.

## Verified Starting State
- `Esi.AI.Backend.Abstractions` defines `IBackendRuntime` and `IBackendModule`.
- `Esi.AI.Backend.Llama.Vulkan` is the only current `IBackendRuntime` backend package and is not registered in Studio.
- Studio model load, SignalR chat, and OpenAI-compatible generation still route through `ModelRuntime` and legacy adapters.
- Legacy runtime implementations cover LLama CPU/CUDA/SYCL, OpenVINO, vLLM/SGLang Python bridge, and dotLLM.
- The target package list currently documents Llama CUDA12/SYCL, OpenVINO, vLLM CUDA12/XPU, and Llama Vulkan.
- Multiple backend modules need multi-runtime DI resolution; current Vulkan module registration uses a single-service registration.
