# Summary

The chat error was caused by `VllmXpuRuntime.LoadAsync` continuing after a failed vLLM XPU model-load response, storing the empty `model_id`, and exposing a model that could not create a chat session. The runtime now rejects failed load responses with the bridge error and rejects successful responses with an empty model ID before publishing loaded state. Regression tests cover failed, malformed, and valid responses.
