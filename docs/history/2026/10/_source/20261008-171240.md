## Follow-up finding
No single cross-backend quantized artifact is established by the current application contracts. Supported model formats are mapped backend-specifically; Qwen3.8 GGUF is documented to fail with the current OpenVINO 2026.3 runtime, while the working OpenVINO Qwen3.8 artifact is a separate IR directory. Existing real-model reference coverage is incomplete for SGLang and dotLLM. A common artifact is therefore an unresolved feasibility gate, not a selected quantization.
