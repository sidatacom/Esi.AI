## Findings

- `Models.razor` toggles the selected backend and calls `IDataService.LocalModel_UpdateAsync` with `ModelCompatibilityUpdate`.
- `DataService.LocalModel_UpdateAsync` persists `CompatibleBackendsJson`, then calls `LocalModel_ReadAsync`.
- `BackendModel_ReadAsync` calls `LocalModel_ReadAsync` on every invocation and filters the returned models by the requested backend.
- `Backends.razor` calls `BackendModel_ReadAsync(ConfigurationBackend.Sglang)` when the SGLang tab is selected. Initial page setup reads only the initially selected backend, normally LLama unless an OpenVINO path is saved.
- No backend-model cache or invalidation step is required for this path. The only nearby model cache is for memory-estimation profiles.
- The focused integration test verifies manual assignment controls the backend picker, but uses vLLM rather than SGLang and there is no UI test for tab refresh.
- Verdict: after metadata persistence, a fresh page reload followed by selecting the SGLang tab should be sufficient, provided the model is still discoverable by the local filesystem scan and is not marked deleted. A reload alone may not query SGLang if initialization selects LLama or OpenVINO.
