# Session Request

User requested an exhaustive attempt to obtain Intel GPU VRAM information for Esi.AI Studio, including all available telemetry paths.

## Plan
- Probe installed Intel GPU and telemetry tools.
- Inspect DRM/sysfs/debugfs and process-visible GPU memory data.
- Probe Level Zero core memory properties with verified ABI definitions.
- Compare results and determine what can be integrated without inventing process usage.
- Validate any repository change with a focused build/test.

## Findings
- Level Zero Core reports device capacity: Battlemage 31,023 MiB and UHD 630 28,426 MiB.
- Intel xe DRM `DRM_XE_DEVICE_QUERY_MEM_REGIONS` reports Battlemage global usage: 15,057 MiB of 32,656 MiB in the probe.
- Sysman memory modules remain unsupported on this driver.
- Per-process VRAM usage is not exposed by the available APIs.
