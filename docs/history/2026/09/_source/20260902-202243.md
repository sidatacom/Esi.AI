# Session log

User request:
Gibt es bei Hugging Face einen Filter für die Modellgröße? Bei 12 GB VRAM auf einer Intel-Karte sollen nur Modelle angezeigt werden, die mit einem 128k Context Window hinein passen.

## Assessment
- Hugging Face supports coarse filters such as parameter count, library, task, license, language, and tags.
- Hugging Face does not provide a reliable combined filter for GPU VRAM plus context-window fit.
- Exact fit requires model configuration, quantization, KV-cache settings, runtime overhead, and the actual maximum context length.
- The Esi.AI Models page already exposes coarse parameter-range filtering; an exact fit filter would need local estimation after reading model metadata.
