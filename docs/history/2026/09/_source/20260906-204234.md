# Sitzungsprotokoll

## Anfrage

Die neuen virtuellen Debug-Kommandos `readyness`, `stop` und `restart` testen: eine Debug-Sitzung starten, neu starten und anschließend stoppen.

## Aktionsplan

- [ ] Verfügbare C#-Dev-Kit-Kommandos prüfen.
- [ ] Eine neue Esi.AI-Studio-Debug-Sitzung über `csdevkit.debug.projectDebugLaunch` starten.
- [ ] Die aktive Sitzung über `csdevkit.debug.active.session` ermitteln.
- [ ] Die Host-Bereitschaft über `csdevkit.debug.check.host.readyness` prüfen.
- [ ] Die aktive Sitzung über `csdevkit.debug.restart` neu starten.
- [ ] Nach dem Neustart die Host-Bereitschaft erneut prüfen.
- [ ] Die aktive Sitzung über `csdevkit.debug.stop` beenden.
- [ ] Verifizieren, dass keine aktive Debug-Sitzung verbleibt.

## Voraussetzungen

- C# Dev Kit ist aktiv.
- Der Start erfolgt über die dynamische C#-Dev-Kit-Konfiguration.
- Vor einem neuen Start darf keine alte Studio-Instanz den Port 7010 belegen.
