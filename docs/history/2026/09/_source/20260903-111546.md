# Session Log

## User request

Render download buttons for Hugging Face search results based on the repositories' detected backend compatibility, not on the active search filter.

## Implementation

- Updated `Esi.AI.Studio.Client/Pages/Models.razor`.
- Search rows now derive download targets from `HuggingFaceModel.CompatibleBackends`.
- GGUF and dotLLM/LLama compatibility produces one `GGUF herunterladen` target.
- OpenVINO compatibility produces `OpenVINO herunterladen`.
- vLLM/SGLang compatibility produces `Transformers herunterladen`.
- The selected download library is passed explicitly, so changing the search filter cannot redirect an already rendered download action.
