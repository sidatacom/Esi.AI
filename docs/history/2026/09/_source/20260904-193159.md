# Session Log

## User Request
Explain why the Vulkan row shows a Requirements button even though Vulkan is installed.

## Findings
The matrix action state was keyed only by LLama backend tab and vendor. The unresolved SYCL check for Intel / XPU therefore replaced the Supported text in the separate LLama / Vulkan row.

## Change
The Requirements button is now restricted to the route/vendor combinations used by the matrix:
- LLama / CUDA 12 with NVIDIA / CUDA
- LLama / SYCL 16 with Intel / XPU
- LLama / Vulkan with AMD / ROCm

## Validation
The Studio project built successfully after the Razor change. The active debug session was stopped before the build; port 7010 and the watchdog PID file were free afterward.
