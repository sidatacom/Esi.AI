## Summary
The error was caused by the user setting `chat.byokUtilityModelDefault: "none"`, which prevented VS Code Copilot Chat from assigning a utility model for the selected local main agent. The setting was changed to `"mainAgent"`. The selected `Qwen3.8-27B-int4-ov` model was then loaded through the Studio Backends page on OpenVINO GPU.1.

Validation: Studio `/v1/models` exposes all four capabilities; the runtime reports the Qwen model loaded; a real `/v1/chat/completions` request returned `chat.completion` successfully with `ESI_CHAT_OK`. Provider `0.1.10` is installed. The supervised Studio session remains running for interactive chat validation.
