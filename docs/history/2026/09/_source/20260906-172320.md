# EsiMCP Unified VS Code Commands

## User request

Refactor the old `debug_*` MCP tools into exactly two public tools:
- `vscode_debug_execute_command`
- `vscode_debug_list_commands`

Refactor the old terminal MCP tools into exactly two public tools:
- `vscode_terminal_execute_command`
- `vscode_terminal_list_commands`

Use the same command-list/command-execute logic already used by the C# Dev Kit wrapper. Preserve the existing command implementations behind the new dispatchers.

## Implementation

- Public MCP catalog now exposes only `vscode_debug_list_commands`, `vscode_debug_execute_command`, `vscode_terminal_list_commands`, and `vscode_terminal_execute_command` for the legacy Debug and Terminal command areas.
- Existing `debug_*` and `terminal_*` handlers remain the command implementations and are dispatched by `commandId` with an object in `arguments`.
- Updated the VS Code debug skill to use the new C# Dev Kit command IDs `csdevkit.debug.stop` and `csdevkit.debug.restart` through `csharp_devkit_execute_command`.

## Summary

The legacy Debug and Terminal functions are now grouped behind the requested VS Code list/execute tools, and the debug workflow references `csdevkit.debug.stop` and `csdevkit.debug.restart` instead of the removed `mcp_esimcp_debug_stop` tool.
