## Summary

The reported errors were caused by two related issues: structural protobuf contract changes cannot be applied to an already loaded assembly, and the direct CoreCLR server launcher was missing the runtime switch required for .NET Hot Reload. The Studio debug configuration still has `hotReloadEnabled` and the Blazor `inspectUri`; the server profile now also passes `DOTNET_MODIFIABLE_ASSEMBLIES=debug`.

For changes to `.proto`, generated contracts, project references, or other assembly metadata, use the existing `Esi.AI Studio (Server Debug)` restart. Supported UI and code edits can use Hot Reload after that rebuilt session is running.
