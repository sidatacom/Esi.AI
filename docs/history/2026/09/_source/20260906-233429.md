## Working hypothesis
The current semaphore serializes callers but does not expose/reuse the same load task. A per-configuration shared task in DataService should make concurrent requests await one native model load.

## Changes
- Replaced the per-configuration semaphore with `Lazy<Task<ModelLoadStatus>>` single-flight coordination.
- Direct configuration loads and API AutoLaunch loads now share the same in-flight task.
- Waiting HTTP requests use `WaitAsync`; request cancellation no longer cancels the shared native model load.
- Completed and faulted load tasks are removed from the coordinator so later loads can retry.
- Preserved the controller fast path for an already loaded configuration and the loading-state wait path.
