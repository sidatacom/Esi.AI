## Outcome
- Added a 128 KiB serialized-size limit per prerender snapshot and stripped top-level/per-model `LoadLog` content before transferring loaded-model status.
- Added a backend-tab snapshot containing only last-selected backend fields and enabled backend IDs; the Hugging Face token and remaining `ApplicationSettings` are not serialized. The initial settings read is skipped only when that snapshot is restored; settings reads before writes remain intact.
- Home, Provider, Chats, and Models consume restored loaded-model status. Chats and Models also consume bounded local-model lists; Models consumes bounded model-directory lists. Missing or oversized snapshots preserve the existing `IDataService` read path. SignalR subscriptions and update flows remain unchanged.
- Chat transcripts, image previews, provider trace payloads, and arbitrary flow JSON remain excluded. Conditional Settings-page candidates were not changed.
- Validation: `Esi.AI.Studio.Client` build passed (exit code 0); editor diagnostics reported no errors in changed files; full-page browser reloads of `/backends`, `/models`, `/chats`, `/provider`, and `/` displayed their expected content without visible runtime errors. InteractiveAuto prerender markers were present. The generated marker payload is protected by Blazor, so field-level transfer was not inspected in the DOM.
