# Summary

The OpenVINO device enumeration already returned the discrete card, but its name is `Intel(R) Graphics [0xe223]`, unlike the more familiar Battlemage/B580 marketing names. The preferred-device selector did not recognize that PCI ID and therefore chose the first result, the UHD 630 iGPU. It now treats `0xe223` as the discrete Intel GPU marker.

The backend worker returns `Intel(R) Graphics [0xe223] (dGPU)`, and the Backends page displays it as the selected OpenVINO route. The existing OpenVINO device ID and routing policy remain unchanged. Worker and Studio builds succeeded; the Studio host reached readiness; the native worker probe and browser UI were both verified. Editor diagnostics report no errors in changed source files.
