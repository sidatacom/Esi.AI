# Session Log

User request:
- Explain why the OpenVINO Core creation message appears three times in the runtime log.

Initial hypothesis:
- The native logger callback or OpenVINO Core initialization is being registered/invoked multiple times, causing one logical message to be appended repeatedly. A focused disconfirming check is to inspect `OpenVinoModelLoader` callback setup and the diagnostics/load call paths.

Plan:
- [completed] Trace the OpenVINO Core log emission and callback registration.
- [completed] Remove the duplicate emission at its owning boundary while preserving useful runtime logs.
- [not started] Build and verify the OpenVINO log output.

Findings:
- The OpenVINO C# API logs `OpenVINO Core instance created successfully` from every `Core` constructor.
- The Studio creates Core instances for diagnostics, model pipeline work, and VRAM statistics.
- `OvLogger` uses a process-wide callback, so those lifecycle messages were copied into the model loader log and could appear three times.

Implementation:
- Ignore only the OpenVINO Core creation lifecycle messages in the model loader callback.
- Keep model-load progress, errors, and measured VRAM messages visible.
