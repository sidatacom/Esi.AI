# Session Log

Add an installation routine and an installation prompt for the Esi.AI Studio VS Code model provider, following the existing EsiMCP pattern.

## Initial hypothesis

The `vscode-esi-ai-studio` extension already contains the provider implementation and packaging scripts, but lacks a repeatable local VSIX installation workflow and a prompt that guides an agent through installation and verification.

## Planned checks

- Inspect the EsiMCP packaging and installation guidance.
- Add a platform-appropriate installation routine for the Studio provider.
- Add a reusable VS Code prompt for installation and verification.
- Build/package the extension and verify installation with the VS Code CLI.
