## Summary
Refactored the runtime facade from `ModelLoader` to `ModelRuntime`. `ModelRuntime` now owns LLama and OpenVINO, implements `IHostedService` and `IDisposable`, initializes OpenVINO in `StartAsync`, and unloads both runtimes in `StopAsync`. The old shutdown-only adapter was removed; Studio registers the same `ModelRuntime` singleton as the hosted service and application dependency. Added `ModelRuntimeTests.StopAsync_WhenNoModelsAreLoaded_LeavesAllRuntimesUnloaded`.

Updated `Backends.razor` to show `CHECKING RUNTIMES` while the shared runtime state is being queried after navigation, preventing a transient and misleading `NO MODEL LOADED` display. The Studio build passed, and browser verification confirmed that `Backends -> Chats -> Backends` preserves the loaded OpenVINO model and settles at `MODEL LOADED` with `1 ACTIVE`.

Moved loader construction into the `ModelRuntime` singleton registration. `LlamaModelLoader` and `OpenVinoModelLoader` are no longer independently registered application services; `ModelRuntime` owns their lifetime and disposal while retaining constructor injection for focused tests.

Moved the production loader construction into `ModelRuntime` itself. `Program.cs` now uses the simple `AddSingleton<ModelRuntime>()` registration; the explicit loader constructor remains available for unit tests and dependency-controlled construction.

Validation: full Core test run passed with 17 passed, 0 failed, 2 skipped; focused `ModelRuntimeTests.StopAsync_WhenNoModelsAreLoaded_LeavesAllRuntimesUnloaded` passed; Studio build passed after the constructor and DI change; browser verification passed; compiler diagnostics were clear before the UI update. `git diff --check` still reports the repository's existing CRLF-related whitespace warning in the touched `Program.cs` lines.
