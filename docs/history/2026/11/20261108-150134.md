# Sitzungsprotokoll

## Nutzeranfrage

Audio-Chat in Esi.AI Studio für ein Avatar-Terminal implementieren. Das Terminal aktiviert sein Mikrofon über das Radar und streamt kontinuierlich Audio. Die Verarbeitung soll auf dem Desktop laufen: Sprache-zu-Text mit Whisper.cpp und Text-zu-Sprache mit Piper; Audioantworten werden über SignalR zurück zum Terminal gestreamt. Das LLM-Backend soll Vulkan verwenden; Audio darf nicht an NVIDIA gebunden sein.
