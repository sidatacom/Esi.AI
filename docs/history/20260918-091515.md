# Session

## User request
Die SignalR- und Page-State-Struktur soll sauber neu organisiert werden: pro Page genau ein Base-State-Objekt, darin verschachtelte State-Klassen pro Bereich, wiederverwendbare States wie ActiveModelsState für Chats und Backends, CRUD-Methoden im SignalR-Service für Base- und Nested-States, Read/Update für alle State-Klassen sowie Create/Delete nur für Collections. Alte Strukturen sollen vollständig entfernt werden; Abwärtskompatibilität ist nicht erforderlich.
