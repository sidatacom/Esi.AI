# Session

## Request
Continue investigating the duplicate loaded-model entries shown in Studio.

## Finding
`ModelRuntime.LoadedModel_Read()` concatenated active runtime statuses with pending model statuses. During a reload, an already-loaded Python model and its pending replacement shared the same backend and model path, so both were published and rendered.

## Change
Pending statuses are now suppressed when the same backend/model path is already loaded. This preserves a single logical runtime entry during reloads.
