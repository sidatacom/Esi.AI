## User request
Das im VS-Code-Model-Picker sichtbare Esi.AI-Studio-Model kann nicht ausgewählt werden; `Qwen3` soll auswählbar sein.

Die von `LanguageModelChatProvider` gelieferten Modellinformationen enthalten nicht alle verpflichtenden Metadaten. Die aktuelle VS-Code-API verlangt `capabilities`; ein reines Textmodell muss deshalb `capabilities: {}` liefern.
