## Findings
The VLM wrapper had been changed in commit `1429946` from the working `ref streamer_callback` native ABI to manually allocated unmanaged callback memory passed as `IntPtr`. The native VLM declarations provide the same `ref streamer_callback` overload as the LLM declarations. The VLM wrapper now uses the ref-struct ABI for both direct prompt and history generation, keeping the delegate alive until native generation returns.

The Esi.AI OpenVINO chat session now invokes `vlmPipeline.Generate(prompt, callback)` and forwards each callback delta to the server streamer. The OpenAI-compatible controller already emits each received delta as an SSE chunk and sends `[DONE]` after generation completes.
